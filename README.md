# Health Information System (his)

A program to simulate basic health information system for managing clients and health program/services.

The program includes:

- Create a health program (e.g TB)
- Register new client
- Enroll a client in one or more programs
- Search for a client profile
- Expose client info via API
- Login for doctor/user (implicit, basic login)

## build

```sh
make build
```

This builds the go code.

## run

```
./his # .\his.exe for windows
```

Runs the executable
